# Xclipse940-RADV

Experimental Mesa RADV Vulkan userspace driver port for the
Samsung Xclipse 940 GPU found in Exynos 2400 / Exynos 2400e devices.

Current target:
- Samsung Galaxy S24 FE
- Exynos 2400e / S5E9945
- Xclipse 940
- Samsung SGPU DRM kernel driver

Status: early development / experimental.
